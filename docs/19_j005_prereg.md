## 0. 为什么有 J005（承接 dd/18）
J004 阳性对照 POS（DOPE:CHOL 80:20，14 nm 盒，随机混合）未形成非层状相 → 整批不下结论；α=0（T0）随机混合起始四次失败，无参照。
J005 修三件事：① 阳性对照换 20 nm 盒（POS20）+ 预组装 H_II 起始（POS_HII）；② 加层状阴性对照 NEG（DOPC:CHOL 80:20）；③ T0/T100 改预组装多层（T0_bil/T100_bil）。并导出**含水**全体系末帧与多帧。

## 2. 判相方法（与 J004 相同脚本与阈值；classify() 未改，仅新增 --hkl 追踪）
1. 数据：每体系含水全体系末帧 confout_W.gro + prod.trr 每 50 ns 一帧含水（转 xtc）。
2. 主判：phase_sq.py（sha256 与 j005-v1 SHA256SUMS 一致），`--sel W --conn`（水珠），阈值 frac 0.08 / 对比度 8× / smin 25（与 dd/18 相同）。辅判：tails、heads 选择；dd/18 的 geo_check.py（水域连通簇、卷绕轴、χ、法向张量）。
3. **时间平均**：取 prod 最后 200 ns 内所有含水帧（每 50 ns，约 4–5 帧，估算）逐帧判相；某相须在 ≥ 2/3 帧一致才计为该相，否则记 DISORDERED/MIXED。帧数 <3 时只报单帧并标「单帧」。
4. 非层状 = HII、Pn3m、Im3m、Ia3d 之一（立方单列）。LAM 须 ≥2 阶且比值 1:2 (±5%)。
5. **POS_HII 专用判据（发车前 box 实测发现，必须预先写死）**：v1 classify 在 2×1 六方胞小盒里因 6 个等价 (10) 峰占满 |q| 壳层、壳均值被峰自身抬高，**完美 H_II 起始结构也判 DISORDERED**（sys.gro / em.gro / eq1 200 ps 均如此；selftest 新增 HIIsmall 复现）。为不改 J004 判据，classify() 原样保留，新增 `--hkl "2,1,0;2,-1,0;0,2,0"`：只追踪起始晶格 (10) 族三条反射，背景 = 同壳层除去这些反射(含 −hkl)的均值；strong = S≥25 且 ≥0.08·smax 且 衬度≥8。
   - POS_HII「保持 H_II」= (10) 族 3/3 strong（≥2/3 帧）且水域连通性为多簇、各簇只沿 z 卷绕；2/3 记「部分保持」；≤1/3 记「已离开 H_II」，再看 classify 结果。
   - 基线（box 实测，--sel W）：起始 sys.gro 3/3，衬度 ~7100–7460；EQ1 200 ps 后 3/3，衬度 480–550；随机混合 POS20/NEG 起始 0/3（衬度 ≤1.2）。
6. 预组装体系须报告「是否离开起始相」：T0_bil/T100_bil 起始 LAM，POS_HII 起始 HII。起始相保留**不等于**该相稳定（可能动力学受困），只作方向参考。

## 3. 预注册闸门（按顺序，前一条不过则后面不下结论）
G1 阳性对照：POS20 末段 classify 判为非层状（HII 或立方）**或** POS_HII 按 §2.5「保持 H_II」。
   - 仅 POS_HII 保持 HII、POS20 未自发形成 → G1 记「弱通过（仅预组装保持）」，后续结论再降一级。
G2 阴性对照：NEG 保持/形成 LAM（不得出现非层状）。
**α 序列（T0_bil、T33/T33_rep2、T67/T67_rep2、T100/T100_rep2/T100_bil）只有在 G1 且 G2 都通过时才可下结论。**
G3 主闸门：α* = 第一个（α 递增）判为非层状相的 α ∈ {0, 0.33, 0.67, 1.00}。α=0 的参照为 T0_bil。
G4 立方相（Pn3m/Im3m/Ia3d）单列报告，不并入 α*。
限定：每个 α n=1（T67、T33、T100 至多 n=2，且起始方法不同时不合并），**一律只作方向性**，不报显著性。J004 与 J005 同一 α 起始不同（随机 vs 预组装）分开列。
